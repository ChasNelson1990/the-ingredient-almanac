# The Ingredient Almanac

A static recipe & kitchen-ephemera site, built from the "Wes Anderson Recipe Website" design.

## Status

Work in progress. Currently live:

- `journal/a-shoyu-made-of-oats.html` — a journal entry on Slow Sauce's oat shoyu and salmon sashimi.

Shared styling lives in `assets/style.css` and `assets/theme.js` (light/dark theme toggle). More pages (front page, recipes, the larder) are on the way.
